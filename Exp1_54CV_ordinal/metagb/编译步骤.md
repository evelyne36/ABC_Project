编译步骤

  1. 确保安装必要的依赖

  # 安装Python开发包和编译工具
  sudo apt-get update
  sudo apt-get install python3-dev gcc build-essential

  # 安装CFFI
  pip install cffi

  2. 进入metagb目录

  cd metagb

  3. 运行编译脚本

  python build_metagb.py

  这会自动：
  - 编译 metagb.c 文件
  - 使用 -O3 优化选项
  - 生成 libmetagb.so 共享库文件（Linux上）
  - 生成Python可以导入的模块

  4. 验证编译结果

  编译成功后会生成：
  - libmetagb.c (CFFI自动生成的包装代码)
  - libmetagb.o (目标文件)
  - libmetagb.so 或 libmetagb.cpython-*.so (共享库)

  5. 测试导入

  python -c "import libmetagb; print('编译成功')"

  常见问题

  如果遇到编译错误：

  - 缺少gcc: sudo apt-get install gcc
  - 缺少Python.h: sudo apt-get install python3-dev
  - 权限问题: 使用 sudo 或在虚拟环境中操作

  手动编译（可选）

  如果不想用CFFI，也可以手动编译成共享库：

  gcc -O3 -fPIC -shared -o libmetagb.so metagb.c -lm

  但这样需要自己编写Python绑定代码，推荐使用CFFI方式。
