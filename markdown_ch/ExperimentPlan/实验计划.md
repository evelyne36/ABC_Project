# MetaGB 实验规划文档

## 一、实验背景与目标

### 1.1 基础信息
- **版本基础**: Version 3
- **核心研究问题**: 
  - MetaGB适用的场景识别（合成数据 + 实际数据双路线）
  - MetaGB的性能特征（鲁棒性 + 计算复杂度）
- **已知优势**: MetaGB在股票等时序预测的连续任务中表现优异（因XGBoost的分裂变量缺乏预测能力）

### 1.2 研究视角
- **调试观察**: 保存训练集和验证集的损失(MSE)变化曲线，判断欠拟合/过拟合状态
- **理论深化**: 持续阅读相关论文，发现更多insights

理解MetaGB各超参数对模型性能的影响机制

### A.2 数据集选择

- **选择理由**: 数据规模适中、特征明确、结果可解释性强

### A.3 实验方法
- **方法**: 10-fold交叉验证 + 网格搜索
- **参数网格**（需明确定义）:

  metagb_params = {

### A.4 评估指标
- 训练集MSE

### A.5 输出结果

- 参数交互效应分析
- 最佳参数组合

## 模块B: 合成数据集性能测试

### B.1 实验目标
在可控条件下测试MetaGB的鲁棒性和优势场景

### B.2 数据集设计

#### B.2.1 非线性模式测试集（固定样本数：4000，特征数：10）

**无噪声基准组**:
1. `make_regression_square_noise(0)` - 平方项非线性
2. `make_regression_sin_noise(0)` - 正弦波非线性
3. `make_regression_square_sin_noise(0)` - 平方+正弦混合
4. `make_regression_sigmoid_noise(0)` - Sigmoid非线性

**噪声鲁棒性测试组**（高斯噪声std: 0.1, 0.3, 0.5, 0.6, 1.0, 10.0）:
- 每种非线性 × 6种噪声水平 = 24个数据集
- 噪声添加方式: `y = f(X) + N(0, σ)`

#### B.2.2 特征交互测试集

**XOR类交互数据集**:
- **目的**: 测试MetaGB处理特征交互的能力
- **设计**: 
  - 2D XOR: `y = (x1 > 0) XOR (x2 > 0)`
  - 3D XOR: 扩展到三个特征
  - 多维XOR: 4-5个特征的交互模式
- **假设**: MetaGB通过叶节点的`β·x`学习应该需要更浅的树

**叶子线性数据集**:
- **目的**: 测试分段线性函数的学习能力
- **设计**: 
  ```
  y = x1 * x2, if x1 > 0
  y = -x1 * x2, otherwise
  ```
- **变体**: 3-5个不同斜率的分段区域
- **假设**: MetaGB应该用更少的树达到更低误差

**条件-预测分离数据集**:
- **目的**: 测试特征角色分离的效果
- **设计**: 
  - 分类特征（如星期几）定义区域
  - 连续特征定义区域内的预测模式
- **示例**: 
  ```
  region = categorical_feature
  y = slope[region] * continuous_feature
  ```
- **假设**: 使用显式特征分离的MetaGB应该表现优异

**高维稀疏交互数据集**:
- **目的**: 测试高维稀疏场景下的特征选择能力
- **设计**: 
  - 总特征数: 100+
  - 相关特征: 5-10个
  - 交互类型: 乘法交互
- **示例**: `y = x1*x2 + x3*x4*x5 + noise`（其余95个特征为噪声）
- **假设**: MetaGB的独立特征采样应该更高效地发现真实交互

### B.3 实验设置
- **基准脚本**: `compare_metagb_xgboost.py`
- **数据生成函数**: 
  - `generate_synthetic_regression()`
  - 各种`make_regression_*_noise(noise_level)`
- **主函数**:
  - `main()` - 标准比较
  - `main_v3()` - 测试不同`pred_fraction`值（0.0-0.8）

### B.4 评估方案
- **指标**: RMSE（均方根误差）
- **比较对象**: MetaGB vs XGBoost
- **参数搜索**: 网格搜索最佳超参数组合

### B.5 输出结果
- 不同非线性模式下的性能对比表
- 噪声鲁棒性曲线（噪声水平 vs RMSE）
- 特征交互场景的树深度对比
- 高维稀疏场景的特征选择效率对比

  - `print_summary()`

#### C.3.2 加州房价数据集（California Housing）
- **脚本**: `compare_metagb_xgboost_housing.py`
- **数据来源**: OpenML
- **特殊处理**:

- **参数测试**: `pred_feature_fraction` = [0.0, 0.4, 0.8]
- **注意**: 删除第198行的`pdb.set_trace()`断点

#### C.3.3 交叉验证版本
- **脚本**: `compare_metagb_xgboost_housing_cv.py`
- **方法**: 5-fold交叉验证
- **关键函数**:
  - `cross_validate_xgboost()`
  - `cross_validate_metagb()`
  - `grid_search_xgboost_cv()`
  - `grid_search_metagb_cv()`
- **输出**: 各折平均MSE ± 标准差

### C.4 批量测试流程

#### 回归数据集（优先）
1. **执行方案**: 10-fold交叉验证 + 网格搜索
2. **参数网格**（统一配置）:

4. **结果汇总**:
   - 最佳参数配置表

## 模块D: 时序场景大规模验证

### D.1 实验目标
验证MetaGB在时序预测任务中的优势，挖掘深层insights

### D.2 数据集选择
- **股票预测数据集**: 
  - 多支股票的历史价格数据
  - 技术指标（MA, RSI, MACD等）
  - 市场宏观指标

### D.3 时序特性考虑
- **数据划分**: 时间顺序划分（避免数据泄露）
  - 训练集: 前70%时间段
  - 验证集: 中间15%
  - 测试集: 最后15%
  
- **滚动窗口验证**: 模拟真实交易场景

### D.4 Findings挖掘方向
1. MetaGB在不同市场状态下的表现（牛市/熊市/震荡）
2. 预测时间跨度的影响（日度/周度/月度）
3. 特征重要性的时间稳定性
4. 与传统时序模型（ARIMA, LSTM）的对比

## 模块E: 性能边界实验

### E.1 实验目标
探索MetaGB在不同复杂度设置下的性能边界

### E.2 实验设计

#### E.2.1 回归复杂度梯度实验
**假设**: 过拟合风险随复杂度递增

1. **Constant Bias**: 叶节点输出常数
   - 设置: `pred_feature_fraction = 0.0`
   
2. **Single-variable Regression**: 叶节点单变量线性回归
   - 设置: `pred_feature_fraction = 0.1-0.3`（仅选少量特征）
   
3. **Multi-variable Regression**: 叶节点多变量线性回归
   - 设置: `pred_feature_fraction = 0.5-0.8`
   
4. **Functions Regression**: 叶节点复杂函数拟合
   - 设置: 自定义叶节点函数类型

**评估维度**:
- 训练集 vs 测试集误差（过拟合gap）
- 模型复杂度（参数量）
- 训练时间

#### E.2.2 聚合策略实验

1. **ScoreAggregation Only**:
   - 仅在split阶段聚合分数
   
2. **ScoreAggregation + FeatureAggregation**:
   - Split阶段聚合分数 + Prediction阶段聚合特征

**比较维度**:
- 预测精度
- 计算开销
- 特征选择稳定性

## 七、风险与应对

### 7.1 潜在风险
1. **计算资源不足**: 网格搜索计算量大
   - 应对: 优先级排序，分批执行，使用分布式计算
   
2. **数据集不平衡**: 某些数据集可能不适合MetaGB
   - 应对: 记录失败案例，分析原因，形成负面案例库
   
3. **超参数空间过大**: 搜索时间过长
   - 应对: 先使用随机搜索缩小范围，再精细网格搜索

### 7.2 质量保证
- 每个实验至少运行3次（不同随机种子）
- 关键结论需要统计检验（p < 0.05）
- 代码通过单元测试和集成测试
- 实验结果可复现（保存随机种子和完整配置）
