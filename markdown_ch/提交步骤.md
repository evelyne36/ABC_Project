## 仓库搭建流程
(1)建立本地仓库：git clone [xx_url_xx.git](https://github.com/AncD8972/ABC_Project.git)
> 注意cd到含.git目录下
(2)git remote -v
(3)链接远程仓库：git remote add upstream [xx_url_xx.git](https://github.com/AncD8972/ABC_Project.git)
(4)git remote -v
(5)git checkout -b "your-branch-name"
(6)修改代码并记录当前所有文件变动:git add .
(7)提交到本地仓库：git commit -m "your-commit-message_Description"
(8)提交到远程仓库分支：git push origin "your-branch-name"
