# tabarena_30 启动指南

## 工程目的

`tabarena_30` 用于把 TabArena 中 binary / multiclass 的昂贵大数据任务与旧工程解耦。流程是先读取既有 `xgb_cpu` 最优参数作为 backbone，再只搜索 MetaGB 专属的 30 个组合：

- `pred_feature_fraction`: 0.1 到 1.0，共 10 档。
- `metagb_score_agg`: 0 / 1 / 2，共 3 档。
- 总计 `10 * 3 = 30` 个 `current_metagb` 候选。

该工程不会继续对这些大数据做完整 Random300 MetaGB 搜索，目的是把计算量压到可控范围。

## 数据与预处理约束

- `in_vehicle_coupon_recommendation.csv` 已从默认 binary 队列中移除，因为严格缺失行删除后仅剩 108 行。
- `drop` 预处理现在先删除任意特征缺失的行，再丢弃离散列；这保证 HR 等数据的 drop 与 onehot 使用同一批非缺失样本。
- `onehot` 保持先删除缺失行，再对类别列做 one-hot。
- TabArena 缺失行删除率见 `tabarena_30/audits/tabarena_missing_drop_rates.csv`。
- 计算优先级见 `tabarena_30/audits/queue_priority.csv`，已按计算压力从小到大排序；用户标记的 `1epoch/若干天` 级慢任务放在最后。

## 推荐 full 启动

建议使用四个分组入口，避免 binary/multiclass 或 drop/onehot 混在同一个任务队列里：

```bash
TASK_WORKERS=15 N_JOBS=1 bash tabarena_30/run_linux_binary_drop.sh
TASK_WORKERS=15 N_JOBS=1 bash tabarena_30/run_linux_binary_onehot.sh
TASK_WORKERS=15 N_JOBS=1 bash tabarena_30/run_linux_multiclass_drop.sh
TASK_WORKERS=15 N_JOBS=1 bash tabarena_30/run_linux_multiclass_onehot.sh
```

这四个入口分别读取：

- `tabarena_30/configs/binary_drop_datasets.txt`
- `tabarena_30/configs/binary_onehot_datasets.txt`
- `tabarena_30/configs/multiclass_drop_datasets.txt`
- `tabarena_30/configs/multiclass_onehot_datasets.txt`

先用 dry-run 检查命令展开：

```bash
DRY_RUN=1 bash tabarena_30/run_linux_binary_drop.sh
DRY_RUN=1 bash tabarena_30/run_linux_binary_onehot.sh
DRY_RUN=1 bash tabarena_30/run_linux_multiclass_drop.sh
DRY_RUN=1 bash tabarena_30/run_linux_multiclass_onehot.sh
```

`Food_Delivery_Time.csv` 是 regression onehot 剩余任务，但计算太慢，当前按要求放弃，不提供 regression onehot 启动入口。

先跑较小数据，保留 `--dry-run-tasks` 检查任务和 backbone 来源：

```bash
python3 tabarena_30/scripts/exp1_tabarena30_all.py \
  --mode full \
  --task-types binary multiclass \
  --models current_metagb \
  --categorical-handling drop \
  --max-candidates 300 \
  --outer-folds 5 \
  --inner-folds 4 \
  --task-workers 15 \
  --n-jobs 1 \
  --dry-run-tasks
```

正式后台运行示例：

```bash
nohup python3 tabarena_30/scripts/exp1_tabarena30_all.py \
  --mode full \
  --task-types binary multiclass \
  --models current_metagb \
  --categorical-handling drop \
  --max-candidates 300 \
  --outer-folds 5 \
  --inner-folds 4 \
  --task-workers 15 \
  --n-jobs 1 \
  --progress-every 10 \
  --run-id tabarena30_drop_full_$(date +%Y%m%d_%H%M%S) \
  > tabarena_30/nohup_logs/tabarena30_drop_full.log 2>&1 &
```

onehot 版本只需把 `--categorical-handling drop` 改为 `onehot`。极慢任务，例如 `Bioresponse 1epoch/132h`、`hiva 1epoch/7天` 这类，应放在队尾或单独服务器运行。
