# tabular_extra_random300 启动指南

## 工程目的

`tabular_extra_random300` 用于 TabPFN 之外的补充 tabular 数据。实验架构统一为 nested CV：

- 外层 5 折：报告泛化性能。
- 内层 4 折：在外层训练集内选择候选参数。
- 每个模型默认 Random300 候选。
- 默认预处理为 `ordinal`，可按需要切换 `drop` 或 `onehot`。

选择标准是 `MetaGB 匹配度 + 时间经济性`。因此优先使用行列规模较小、特征语义可能带来局部统计收益、且 `samples * features * features` 压力较低的数据。

## 数据清单

- 全量候选清单：`tabular_extra_random300/candidate_inventory.csv`
- 当前筛选清单：`tabular_extra_random300/selected_manifest.csv`
- 当前已落盘数据：`tabular_extra_random300/data/*.csv`
- OpenML 下载记录：`tabular_extra_random300/openml_download_manifest.json`

本次已从本地 TabPFN 工程复制第一批可运行数据，并从 OpenML 额外下载：

- `binary__phoneme.csv`
- `binary__pc1.csv`
- `multiclass__balance-scale.csv`

`multiclass__mfeat-karhunen.csv` 下载时遇到 SSL EOF，已记录为失败，可后续重试。

## 推荐 full 启动

Linux 一键后台启动：

```bash
bash tabular_extra_random300/run_linux_full.sh
```

可选环境变量：

```bash
HANDLING=drop TASK_WORKERS=15 N_JOBS=1 bash tabular_extra_random300/run_linux_full.sh
```

第一批低成本数据：

```bash
nohup python3 tabular_extra_random300/scripts/exp1_random300_all.py \
  --mode full \
  --task-types regression binary multiclass \
  --models xgb_cpu current_metagb \
  --regression-datasets regression__energy_efficiency.csv regression__space_ga.csv regression__kin8nm.csv \
  --binary-datasets binary__credit-approval.csv binary__kc1.csv binary__phoneme.csv \
  --multiclass-datasets multiclass__vehicle.csv multiclass__segment.csv multiclass__balance-scale.csv \
  --categorical-handling ordinal \
  --max-candidates 300 \
  --outer-folds 5 \
  --inner-folds 4 \
  --task-workers 15 \
  --n-jobs 1 \
  --progress-every 50 \
  --run-id tabular_extra_random300_ord_full_$(date +%Y%m%d_%H%M%S) \
  > tabular_extra_random300/nohup_logs/tabular_extra_random300_ord_full.log 2>&1 &
```

若需要对比 feature processing，可把 `--categorical-handling ordinal` 改为 `drop` 或 `onehot`，但建议单独 run-id 保存，避免混在同一结果目录。
