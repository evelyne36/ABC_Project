0016 0. 审计口径与状态标签
0017 “正文证据”只指 8 页 main manuscript 中明确表述、公式、表格和实验。
0018 “附录证据”指 Technical Supplement A–G 中已完成的实验与公式；引用附录不等于它证明了审稿人的主张。
0019 “可由现有材料主要回应”：问题主要是解释、定位或承认既有事实，无必要新增实验。
0020 “部分回应”：已有相关实验，但缺乏某个关键反事实或因果归因；应明确证据边界。
0021 “尚未直接覆盖”：正文/附录均无该对照或验证，若希望实质性消除疑虑，需新增证据。
0022 所有新增实验均须保持正确的数据划分、统一指标方向、公平调参协议；不能预设结果会支持 CrossGB。

0028 附录：Appendix C/D 的机制合成与消融支持模型在部分结构上有效；没有 PL Trees 或 LinXGBoost 的直接跑分。
0029 判定：尚未直接覆盖     已有概念区别，却没有证明相对于“线性叶本身”的额外实用价值。
0030 下一步：N1：在共享划分和可兼容任务上补近似 boosted linear-leaf 基线；W1：用结构对照表界定“独立选择 + predictive-aware score”的组合贡献。
0031 Q2  Table 2 缺失 Standard Split + Predictive Leaf 反事实
0032 正文：§4.3 Table 2 有 XGBoost、BiasOnly、SplitOnly、Full；没有标准分裂打分与 predictive leaf 的组合。
0033 附录：Appendix D.1–D.3 Tables 10–12 给出 16 变体、3 seeds、10/20 维和配对效果；主要比较沿 BiasOnly→SplitOnly→Full 的路径。
0034 判定：部分回应     已有组件效应不等于证明 full predictive-aware scoring 在 predictive leaf 存在时优于标准 scoring。
0035 下一步：N2：在同一固定 backbone 上新增 LeafOnly（standard scoring + predictive leaves）；形成更完整的机制比较，并核对各 variant 实际定义。

0039 判定：部分回应     目前有“失败现象”和统计描述，没有可检验的失败机制。
0040 下一步：N4：优先复用已有 CPU 模型/日志，对比特征采样、局部残差、叶模型/梯度和 selected p；与 Kin8nm 等正例对照。

0137 3. 真正缺失的新实验证据：最小充分方案

0139 N1｜最近邻 linear-leaf 方法直接对比     [P0]
0140 覆盖：Q1 / Ww3 / T1 / J1

0142 最小新实验：优先 PL Trees、LinXGBoost；可行时补 LightGBM linear_tree。至少机制合成数据（regime slope、feature switch + negative control）和真实回归正/负例；同样数据划分、计算资源及清晰的 tuning budget。对仅回归兼容的实现不强求分类。

0155 交付形式：新增 R3: budget–performance 曲线与单位成本收益表；同时标记算法 runtime 与包含搜索的总 budget。

0157 N4｜CPU 等大幅退化的失败机制证据     [P0/轻量]
0158 覆盖：Q3 / T2 / J2
0159 现有证据：Appendix E Table 14 已给出 CPU：RMSE 2.1868→3.9344，且折间差异和耗时显著；G 未针对 CPU 解释。
0160 最小新实验：优先后处理模型与候选日志：追踪 p/候选比例、最佳 leaf features、leaf sample size、shrinkage 和不同局部残差形态；必要时最小固定-backbone对照 CPU vs Kin8nm。
0161 交付形式：新增 R4: 1 张正/负例机制对照表 + 简短诊断，明确哪些是实测相关、哪些只是推测。
0162 边界：  不要把 Correlation 直接写成 causal diagnosis；负结果必须如实保留。
0163 N5｜k=1/2/3 / affine leaf 容量消融     [P1]
0164 覆盖：T4 / J4 / V2
0165 现有证据：p 的 dose-response 调整候选池，而不是每个叶同时建模 k 个预测特征。
0166 最小新实验：可采用阶段 I 固定 routing 比 k=1,2,3 (+affine k=1)；若宣称全算法性能，要阶段 II 完整适配 split search。合成机制覆盖单一 slope、多变量交互、负控，并选正/负真实数据。
0167 交付形式：新增 R5: capacity–RMSE–runtime–overfitting 对比；文本明确 fixed-routing 和 full-model 的差别。
0168 边界：  k=1 不必处处最好，但应显示参数预算、解释性或运行成本的合理折中。
0169 N6｜Forecasting 多时间切分稳健性 / 专用基线     [P1]
0170 覆盖：J3
0171 现有证据：Appendix B.4/F 已有合法的单次时序划分与完整 RMSE；尚无多 cutoffs、persistence/AR 家族对照。
0172 最小新实验：优先 Exchange rate h=6/12 与 ILI h=1/6/12；复核 target construction/normalization、绝不使用未来数据。增加滚动起点/多切分与 persistence、季节性 naive、简单 AR；统一 horizon 和 train/test 时间。
0173 交付形式：新增 R6: 时序 cutoffs 的 mean±dispersion / gain + forecasting-specific references。
0174 边界：  应报告收益是否仍稳定，不能以单次 69.6% 的提升泛化到所有时间。
0175 N7｜真实数据适用性诊断的外部验证     [P1]

0178 最小新实验：若需要可部署前规则，则锁定 G 评分不再调整，使用独立真实任务、training-only 提取特征，并以 held-out CrossGB vs XGB 真实收益为主要目标；可另报 Full vs SplitOnly 的机制中间量。
0179 交付形式：新增 R7: dataset-level rank correlation / AUC 与置信区间，并公开失败例。
0180 边界：  未形成稳定结果前不应声称已有可泛化 suitability predictor。

0183 现有证据：Supp A 有分类训练公式，暂无直接空间几何演示。
0184 最小新实验：合成 y=1[x1+x2>0]；可视化 XGB / CrossGB 在不同树数下的 margin 和分类界面。先完成理论解释，若版面与计算时间允许再追加图。
