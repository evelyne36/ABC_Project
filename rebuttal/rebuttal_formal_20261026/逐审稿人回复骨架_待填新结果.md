## VVba（7）：优先清晰准确的澄清

可用表述：

> Within a region defined by the ensemble's intersecting leaf routes, the classification margin is a sum of the selected leaf linear terms and constants. Its zero set can therefore be oblique even though each routing split is axis-aligned. This is an expressivity statement, not a guarantee that training recovers a particular boundary.

> Each leaf update chooses either a slope-only term or the constant bias candidate. These alternatives do not form an affine intercept-plus-slope leaf. A slope update vanishes when its selected feature is zero, while the ensemble can still have a nonzero prediction from its base margin and other trees.

> Conditional and predictive candidates are sampled per tree. Independent sampling allows overlap; separate roles do not imply disjoint feature sets. The fraction p concerns the candidate pool, whereas k denotes the number of variables used in one leaf response.

这些段落按原问题取舍，避免在同一回复塞入所有内容。CatBoost排名应引用原对照范围和具体指标；不能用缺少完整raw任务的子集重新计算全表胜率。

## 实际结果决定表述，不先设正结论

| 若观察到 | 回复应如何收口 |
|---|---|
| Full稳定优于LeafOnly | 报告在哪些机制、差多少；据此支持score的额外作用，不外推所有数据 |
| LeafOnly与Full相当或更好 | 明确score不是普遍必要条件；保留角色分离/框架贡献，收缩score收益主张 |
| 最近邻优于CrossGB | 正面加入比较；讨论结构/容量/成本边界，不再以仅胜XGB替代最近邻证据 |
| 等搜索预算后优势消失 | 承认较多搜索计算可能解释部分收益；训练与搜索成本分开，限制实践推荐 |
| Persistence/Ridge更强 | 将原时序增益严格限定到原树基线、原split；不隐去新参考结果 |
| k>1改善 | 说明k1是容量限制；固定路由probe不证明完整新算法，也不称k1最优 |
| E0不兼容 | 不拼新旧四格，先定位；必要时用单独冻结协议重做小面板并标清来源 |

这些分支是证据使用规则，不是事后挑选数据或更换指标的依据。
