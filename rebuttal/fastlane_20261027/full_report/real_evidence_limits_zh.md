# 当前真实数据证据边界

依据本目录 `folds.csv` / `summary.csv` 的最终测试结果；验证集与测试集分别统计。回收快照包含 quick_v1、formal24_v1 与 formal30_class_v1。下表 RMSE 为目标原单位，分类主指标为开发阶段预先约定的 logloss。

| 数据与套件 | CrossGB 测试均值 | 关键对照 | 当前解释 |
|---|---:|---|---|
| website_phishing，formal30，5次 | logloss 0.303519 | XGB 0.326407，常数LGB 0.344166，线性LGB 0.352729 | 对三项已测基线均5/5较好；相对XGB改善7.012%，是目前一个可报告的受限真实正向例子 |
| ILPD numeric，formal30，5次 | logloss 0.514980 | XGB 0.508054，常数LGB 0.506961，线性LGB 0.491811 | 主指标均值落后；不能用另一个次指标的局部正向替代预定主指标结论 |
| Gas turbine CO，formal24，5次 | RMSE 1.604301 | PL 1.486561，常数LGB 1.539618，XGB 1.723689 | 平均优于XGB，但仅2/5配对胜；相对PL和常数LGB分别差7.920%和4.201%，不支持全面优势 |
| Protein，formal24，5次 | RMSE 4.608742 | PL 4.560991，XGB 4.593725 | 落后于PL和XGB；不能只挑较弱对照计为优势数据 |

website 的 accuracy 为0.867954，对三项基线均值0.867181，仅高0.000772，即 **0.077个百分点**。可陈述概率质量的logloss改善；不能把它改写为显著的准确率提升。上述五次重复共享同一个固定真实测试集，反映训练/验证划分敏感性，不是五个独立数据集，也不能据此声称已证明总体显著性。website使用原始特征组合分组，测试集259行，原数据只有103个Suspicious类样本；676个特征组中48组存在标签冲突，这也限制结论外推。分类面板目前仅比较三项可运行树基线，不能扩展为对全部作者基线均优。

CPU activity、Parkinson与Superconductivity当前只落地quick单确认种子。各自CrossGB RMSE为3.036950、10.999953、13.088690；对应最强已测基线为2.428257、10.029665、12.677430，均未形成正向证据。quick是廉价筛查，不足以支持稳定优势或五次确认结论；本目录按完整五种子目标将其覆盖明确显示为1/5。

kin8nm侧文件明确标记 `source.provenance=simulation`，汇总已标为 **simulation**，不能计入真实优势数据数量。其quick结果对部分树基线正向，但仍落后于PL，且只有一个确认种子。

因此当前不能声称“3–5个真实优势数据集”：已有完整真实面板中，只有website的预定主指标呈现对当前三项对照的一致正向；其余完整面板没有对强对照的优势，单种子quick也没有补足该缺口。formal24与formal30中相同的website结果源于同一测试集/相同最终选择，不能重复计数为第二份独立支持。

这限制的是当前可写的结论，不意味着尚未运行的数据或未来预算一定没有优势。后续新增证据应按原先冻结的协议记录，而不是通过改变主指标、排除强基线或累计重复面板来达到预期数量。
