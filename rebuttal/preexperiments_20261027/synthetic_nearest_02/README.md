# 合成机制与近邻直接复核（2026-10-27，第2批）

**建议将“小样本、局部单斜率、无关变量较多、分裂与预测角色不同”作为synthetic主攻。** 最终冻结配置、5个全新数据seed中，CrossGB对补强后的Lin平均RMSE约低2.95%、4/5次更好，实际幅度远小于最初小网格的34%。相对PL/LGB linear的误差差距较大。当前结果支持窄机制和实现成本取舍，不支持一般表格优势。

## 1. 可复现的正向构造

生成器沿用 analysis_20261027/synthetic_mechanism_suite.py，不把已有regime_slope/feature_switch改名当新方法。

- c ~ Uniform(-1,1)，z_1…z_31独立标准正态，ε ~ N(0,0.3²)。共32维，n=240；每个独立生成数据集180训练、60验证。
- s(c)=+1（c<0），否则−1；y=2s(c)z_1+ε。
- c决定区域，z_1提供斜率，其余30个变量无关。所有模型得到同一完整X，不给任何模型真实gate、支持集或分组标签。
- 总体上E[y|c]=0，E[y|z_j]=0，但E[yz_1|c]随区域变号。单靠常数叶的边际均值增益可能看不到根部结构；预测感知评分可利用局部斜率。
- 真实分区下，单斜率足以表示条件均值；全变量仿射叶也能表示它，因此这里不是CGB具有独有函数类。检验的是有限样本下的搜索/估计效率。

## 2. 实验顺序与补强

先声明5个设置，2个开发seed91001–91002；按每方法开发均值冻结配置，再用3个新生成数据seed92001–92003。原生XGB/LGB linear额外给到1024轮、PL给到300轮；不是仅用相同64轮欠拟合对手。全部正负项保留。该阶段332次尝试，324成功；n600/d64的Lin全部8次触及12秒本地上限，没有Lin准确率，不能将超时写成精度失败。

稀疏n240/d32原始复核：CGB 0.34477、Lin 0.52525、PL 1.10322。为排除过强树复杂度造成的对手劣势，额外补测Lin更浅树/正则、PL更深树，共42次成功。较浅Lin改善至0.39355。该补测是看到上一轮结果后的自适应分析，不冒充原预注册确认。

**随后冻结所有参数，再换5个从未使用的数据seed93001–93005，25次成功拟合。** CGB沿用原单树配置，Lin采用较浅配置；不再为CGB添加调参。最终参数、逐seed、时间、哈希与计数均保留。

作者Lin根节点depth=1：max_depth=2是最多一次分裂。另查明原作者代码在局部n≤d或矩阵条件数过大时会退回常数叶，不能将所有深层叶都描述成全变量仿射；浅树补测也减轻了这一影响。保留原作者行为，未修算法。Lin的最后一棵树不缩减语义也保留。

## 3. 最终5个全新数据seed结果

| 方法 | RMSE均值±SD | fit wall中位数 | fit CPU中位数 | RMSE≤0.75次数 |
|---|---:|---:|---:|---:|
| CrossGB | 0.357617 ± 0.018552 | 2.997ms | 2.998ms | 5/5 |
| XGB | 1.926943 ± 0.697155 | 1.172ms | 1.172ms | 0/5 |
| LGB_linear | 1.917907 ± 0.553154 | 3.028ms | 3.018ms | 0/5 |
| PL | 1.196740 ± 0.802311 | 7.551ms | 7.530ms | 2/5 |
| LinXGBoost | 0.368492 ± 0.020793 | 704.312ms | 702.965ms | 5/5 |

CGB对Lin：4/5次更好，平均RMSE比值约降低2.95%；对PL、LGB linear、XGB均5/5次更好。CGB相对XGB/LGB linear平均误差约低81.4%，相对PL约低70.1%。不同seed的误差分布较不对称，尤其PL；完整逐seed和SD保留，不宣称显著性。

冻结配置：CGB为1树、lr=1、depth=3、λ=1、predictor fraction=1；XGB同轮数/深度/学习率；LGB linear为16树、lr=.3、depth3、λ=.1；PL为1树、lr1、depth3、8叶、half_additive、max_var5、λ1；Lin为1树、lr1、作者max_depth2、λ2、min_samples_leaf10。各模型深度语义与叶参数化不同，参数数值相同不代表模型容量严格相同。

**成本解读：** CGB约3ms、LGB linear约3ms、PL约7.6ms、Lin约704ms，XGB约1.2ms。CGB不是所有对手都更快；与LGB linear主要是同量级时间下精度更好，对XGB是更高成本换精度。与Lin的差异包含原生C++与作者Python实现差异，PL含ARM标量兼容和CSV API数据读取，不把这些比值当成算法复杂度加速定理或正式Linux结果。计时不含导入、预处理/HPO；CPU秒另报，无内存峰值/能耗/FLOPs测量。

预先规定的稀疏误差目标RMSE≤0.75，CGB与Lin均5/5达成；PL2/5，另两项0/5。这里只比较冻结工作点，不能声称对手所有配置都无法达标，也未声称找到了最小time-to-quality。

## 4. 配对边界与高维扩展

下表为初始冻结参数后的3个独立新数据seed92001–92003，不能与最终5seed表横向混合统计。

| 设置 | CrossGB | XGB | LGB linear | PL | LinXGBoost |
|---|---:|---:|---:|---:|---:|
| dense_switch__n240__d32__r2 | 1.1791 | 1.9270 | 1.9298 | 1.3071 | 0.5492 |
| offset_switch__n240__d32__r2 | 0.4926 | 0.4491 | 0.3687 | 0.3731 | 0.4582 |
| step_control__n240__d32__r2 | 0.4206 | 0.4150 | 0.3277 | 0.3625 | 0.3443 |
| sparse_switch__n600__d64__r4 | 0.5106 | 2.0612 | 1.9496 | 0.9340 | 未完成/超时 |

- **四个活跃斜率**：相同X/噪声，将一个活跃变量改为四个、信号方差匹配；Lin约0.549明显优于CGB约1.179。支持需要多变量叶时更灵活近邻有利，而非k=1普遍最优。
- **区域截距**：信号改为(sparse_signal+2s(c))/sqrt(2)，维持总体信号方差4；LGB linear和PL约0.369/0.373优于CGB约0.493。不能把纯斜率优势外推到仿射关系。
- **纯阶跃**：去掉斜率只留区域均值，CGB约0.421、LGB linear约0.328，普通均值分裂已能利用信息。
- **n600/d64/四区域**：CGB约0.511、PL约0.934、LGB linear约1.950；CGB约574ms，PL约850ms，LGB linear约14ms。CGB精度较好但代价明显增长；Lin超时，不能写胜过全部近邻。

## 5. 理论含义与下一步

| 对比维度 | 可以支持的判断 | 不能推出的结论 |
|---|---|---|
| 分裂与预测角色 | CGB允许路径外预测变量；路径特征模型可能需要额外结构/迭代 | PL/LGB永远表示不了该函数 |
| 局部统计 | 真函数局部稀疏时，标量估计减少叶参数；Lin仿射模型更灵活 | CGB对所有样本量/相关性必然更准 |
| 单节点搜索 | 当前串行CGB histogram代价含O(n_v C P + C P B)，每候选标量求解 | 标量叶消除了预测候选P的扫描开销 |
| 仿射求解 | 全变量候选的Gram构造和矩阵求解随q增加；作者Lin重复求解代价大 | 所有近邻都用同样全变量密集求解；PL增量求解同样昂贵 |
| 模型资源 | 同一分区下单斜率叶参数少于q维仿射叶 | 整体树/叶数更少，或总内存必然更低 |

1. 优先做**同机制参数扫描**：n=120/240/480/960，d=8/32/64，活跃斜率数1/2/4、区域截距0/.5/1；每个点配对同X和噪声，提前固定seed与预算。这里是后续建议，没有声称已经跑完。
2. 将最终5seed配置带到目标Linux环境，合理扩大PL/Lin/LGB搜索并报告同总搜索预算的效果、总搜索CPU、终拟合与预测；另做冻结配置误差—时间曲线。不要把同轮数速度当主张。
3. 将已知分区与已知活跃变量只用于诊断oracle消融，分开识别路由发现、变量选择和系数估计的贡献，不给正式比较中的CGB额外标签。
4. 真实数据重点回到ILPD、vowel、website等现有观测候选与kin基准；kin自身源于仿真，不能作为真实观测机制证明。新公开表格本轮没有全近邻正例，详见[全部真实扩充结果](../expansion_02/README.md)。
5. 保留dense、offset、step三类对照；若更充分近邻调参抹平优势，则收缩为成本/稀疏结构适用范围，不继续改数据只求胜例。
